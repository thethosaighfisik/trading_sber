📄 ОПИСАНИЕ РЕШЕНИЯ

Реализовано end-to-end решение задачи анализа базиса между фьючерсом и спотом и построения статистической торговой стратегии.

Работа состоит из двух основных этапов:

---

🔹 Часть 1 — Обработка рыночных данных и построение стакана

- Загрузка сырых биржевых событий (trades / order book updates)
- Реконструкция лимитного стакана (order book reconstruction)
- Построение снапшотов рынка: best bid / best ask
- Расчёт mid-price
- Синхронизация временных рядов спота и фьючерса
- Расчёт спреда (basis):  
  futures price − spot price

При неполноте данных применяется fallback на цены сделок с агрегацией в временной ряд mid-price.

---

🔹 Часть 2 — Торговая стратегия (basis trading)

- Оценка динамического hedge ratio с использованием фильтра Калмана
- Построение спреда с учётом изменяющегося хеджа
- Применение фильтра рыночных режимов на основе волатильности
- Реализация стратегии возврата к среднему (mean-reversion):
  - вход в позицию при значительном отклонении спреда от равновесного уровня
  - выход при возврате к среднему значению
- Учёт транзакционных издержек и проскальзывания
- Проведение исторического бэктеста стратегии

---

📊 Результаты:

- Кривая PnL стратегии
- Основные метрики эффективности:
  - итоговый PnL
  - максимальная просадка (Max Drawdown)
  - количество сделок
